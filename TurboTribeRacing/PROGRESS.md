# Turbo Tribe Racing — سجل التقدم (Progress Log)

> لعبة سباق كارتات مستوحاة من أسلوب وميكانيكيات Crash Team Racing (شخصيات وأسماء وأصول أصلية بالكامل).
> المحرك: Unity 6 (6000.0 LTS) — Built-in Render Pipeline — Android (أفقي + تحكم لمسي).
> آخر تحديث: 2026-11-11 — الإصدار 0.4.0 (انظر سجل 0.4 أدناه)

## كيف نكمل لاحقاً
1. اقرأ "الحالة الحالية" و"الخطوة التالية" أدناه، ثم `Docs/DEV_NOTES.md` للتفاصيل التقنية.
2. كل شيء مولّد برمجياً — لا أصول خارجية سوى الخط `LuckiestGuy.ttf` (Apache 2.0).
3. اللعبة تقلع تلقائياً في أي مشهد عبر `GameManager.Boot()`.
4. لتعديل مسار: عدّل `Tools/trackgen/<track>.py` وشغّله (يكتب JSON ويحذّر من المعالم القريبة من الطرق)، ثم `python3 Tools/trackgen/preview.py <json> <png>` (تداخلات)، و`Tools/HeadlessShim/run_sim.sh shortcuts <track>` (هل الاختصارات تحتاج مهارة؟ بالكود الحقيقي)، و`run_sim.sh sim <track>` (سباق حواسيب: سقوط/اصطدام/أزمنة)، و`run_sim.sh export <dir>` + `python3 Tools/check_scene.py <dir>/<track>.obj <json>` (ديكور عائم أو داخل طريق).

## تحديث 0.3 — سجل الخطوات
- [x] 0.3-1 **قفزة الحافة**: `KartController.PredictTakeoff` (متنبئ يتتبع الأرض: 8 نقاط كل 0.045 ث، يكتشف أين تنحني الأرض للأسفل أسرع من الجاذبية أو حافة/فجوة، ويقيس الانفصال حتى أول عودة للتلامس) + `LiftingOff` (اختبار دقيق كل خطوة فرعية). الضغط ضمن 0.32 ث قبل الإقلاع يحمّل القفزة؛ تنطلق عند الحافة بسرعة عمودية `4.6 + 6.6·q²` حيث `q = 1 − (زمن الانتظار/0.32)`. القمم الكبيرة (انفصال ≥ 0.5 م) تطلق المركبة تلقائياً. النموذج نفسه في `Tools/trackgen/jumpsim.py`.
- [x] 0.3-2 **تيربو الهواء**: كل هبوط بعد ≥ 0.42 ث في الهواء = تيربو مدته `(air − 0.22)·1.05` (0.25–2.4 ث، ×1.2 إذا ضغطت القفز في الهواء/حملت قفزة)، وقوته تزيد مع الزمن. لا يُمنح بعد السقوط/الإنقاذ أو الإصابة.
- [x] 0.3-3 **شريط توقيت بمنطقة واحدة**: مركز 0.79، عرض 0.17/0.145/0.12 لكل تيربو، خطأ = اختناق 0.35 ث (TOO SOON / TOO LATE). الواجهة واللمعة على الزر ودخان العادم والشرر كلها تتبع المنطقة الواحدة. الذكاء الاصطناعي يستهدف مركز المنطقة بانحراف حسب المهارة.
- [x] 0.3-4 **انتفاخات نصف الطريق** (`hump`): شبكة مع مقطع أمامي يشتد حتى القمة (62%) ثم ظهر مستدير وأطراف مسلوبة، تصادم أرضي. الحواسيب الجريئة تستهدفها.
- [x] 0.3-5 **إصلاح المرور عبر الطرق المغلقة**: جدران ثنائية الاتجاه (حالة `outsideSide`)، جدران الطرق المجاورة (`TrackInstance.FindForeignWall`)، منع تبديل الطريق عبر جدار، كتل صلبة للديكور والمعالم والأعمدة والبوابات (`Solids` + تجزئة مكانية، ولا تُسجّل فوق طريق)، حد ناعم بعد الأكتاف، جدران منخفضة قابلة للقفز (`lowL/lowR` تصدّ حتى 1.15 م)، الستائر لا تُرسم إذا كان عمودها سيقف على طريق، والتقدم في اللفة ينتقل بالكامل عند تبديل الطريق (هبوط اختصار طويل).
- [x] 0.3-6 **اختصارات سرّية**: `hidden` (بلا خريطة/لافتات)، `detachStart/detachEnd` (فرع يبدأ بجانب الطريق خلف جدار منخفض)، `trail` (مظهر ترابي/ثلجي)، `curtain` (ستائر معلّقة)، `bareL/R`. السقوط من فرع = إنقاذ قبل مدخله. الحواسيب: المهارة ≥ 0.6 فقط تعرف الأسرار.
- [x] 0.3-7 **إعادة تصميم المسارات الثلاثة** (2.14 / 2.17 / 2.19 كم) مع 3 أسرار لكل منها، أقسام داخلية 123–134 م، طرق متقاطعة على مستويات، وحساب موضع بداية الممرات تلقائياً من هندسة الطريق (`Track.hop_line` + `edge_clearance`).
- [x] 0.3-8 **التحقق**: `validate_secrets.py` يبني مقطع الأرض الحقيقي لكل سر ويشغّل نموذج القفز بسرعات 27/30/34 م/ث وتوقيتات مختلفة: كل سر يفشل بلا ضغط، ويفشل بقفزة ضعيفة على السرعة العادية، وينجح بقفزة جيدة (أو متوسطة مع تيربو). معاينة: لا تداخلات على Tiki وDustbowl؛ تحذيرات Glacier عند تفرّع البحيرة الجليدية فقط (تفرّع تدريجي مقصود).

## الحالة الحالية
- الإصدار 0.4 مكتمل. **تمت الترجمة** ضد مكتبات Unity المرجعية (UnityEngine 2021.3 + UI + Editor) بلا أخطاء، عدا تحذير واحد معروف في ملف المحرر `NamedBuildTarget` لأن مكتبة المحرر المرجعية المتوفرة أقدم (موجودة في Unity 6).

- لم يُبنَ APK داخل هذه البيئة (لا يوجد Unity) — استخدم قائمة Turbo Tribe في المحرر أو GitHub Actions. أول فتح في Unity هو أول اختبار بصري حقيقي (اللقطات في Docs مُصيّرة بمحاكي WebGL).
- زمن تحميل المسار زاد قليلاً بسبب الديكور المنحوت (~1.3–1.8 ث على الحاسوب)؛ على الإعداد LOW تُبنى المجسمات المنحوتة بدقة أقل.
