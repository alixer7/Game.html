# نوفا بوت — NOVA BOT

لعبة منصات ثلاثية الأبعاد بروح Astro Bot، مبنية بالكامل بمحرك **Godot 4** ومصمَّمة للهواتف (شاشة أفقية، تحكم لمسي، واجهة عربية).
كل شيء مُولَّد بالكود: المجسّمات (أشكال أولية + شيدرز)، الأصوات والموسيقى (ملفات WAV مُولَّدة)، الخط (DejaVu Sans Bold مرفق).
لا توجد خامات (textures) أو نماذج خارجية، لذلك المشروع خفيف جداً.

> ⚠️ **حالة المشروع:** الكود كُتب وفُحص بأدوات ساكنة (انظر «الأدوات») لكنه **لم يُشغَّل داخل Godot** لأن المحرك غير متوفر في بيئة الكتابة.
> أول ما تفعله: افتح المشروع وراقب لوحة **Output / Debugger**. إن ظهر أي خطأ أرسله لي (نص الخطأ + اسم الملف) وأصلحه في الدفعة التالية.

---

## 1) التشغيل على الحاسوب
1. ثبّت Godot **4.3 أو أحدث** (النسخة العادية، ليست .NET).
2. افتح `project.godot` من مدير المشاريع وانتظر انتهاء استيراد الملفات (WAV / الخط) في أول مرة.
3. اضغط **F5**.

للتجربة على الحاسوب: الماوس يعمل كاللمس (إعداد مفعّل)، وهذه مفاتيح بديلة:

| الفعل | لوحة المفاتيح | يد التحكم |
|---|---|---|
| حركة | WASD / الأسهم | عصا يسار |
| قفز (مرتين = قفزة مزدوجة، وبالضغط المستمر في الهواء = تحليق) | Space | A |
| دوران (يحطّم الصناديق والأعداء) | J / X | X |
| اندفاع | K / C / Shift | B / RB |
| الكاميرا | Q / E / R / F | عصا يمين |
| إيقاف مؤقت | Esc / P | Start |

## 2) التصدير للأندرويد
1. ثبّت Android Studio (أو الحزم: JDK 17 + Android SDK + build-tools) واضبط مساراتها في
   **Editor ▸ Editor Settings ▸ Export ▸ Android**.
2. **Project ▸ Export ▸ Add… ▸ Android**.
3. في تبويب Options: فعّل **Permissions ▸ Vibrate** (للاهتزاز)، ومعمارية **arm64-v8a**.
4. اتجاه الشاشة مضبوط أفقياً في المشروع. وضع الغمر (Immersive Mode) يُنصح بتفعيله.
5. المشروع يستخدم مُصيِّر **Mobile (Vulkan)** لجودة أعلى. إن كان هاتفك قديماً ولا يدعم Vulkan غيّر في
   `project.godot` السطر `renderer/rendering_method="mobile"` إلى `"gl_compatibility"` (بعض المؤثرات ستكون أبسط).
6. المراحل مخزّنة في `levels/*.json` **ونسخة مضمّنة** داخل `scripts/game/level_data.gd`، فلا تحتاج إضافة فلتر `*.json` للتصدير.

نصيحة: من ملف التصدير جرّب **One-Click Deploy** بكابل USB مع تفعيل «تصحيح USB» في الهاتف.

## 3) طريقة اللعب
- **العصا اليسرى** للحركة (يمكن جعلها ثابتة أو عائمة من الإعدادات)، **السحب على يمين الشاشة** لتدوير الكاميرا.
- أزرار: **قفز** (اضغط مرتين للقفزة المزدوجة، وبعدها اضغط مطولاً للتحليق)، **دوران** (هجوم دائري)، **اندفاع** (يعطيك مسافة إضافية في الهواء).
- اجمع **شرارات الطاقة** (العملات)، وأنقذ **الأصدقاء الثلاثة** المختبئين في كل مرحلة، وكسّر الصناديق، ثم ادخل **بوابة النهاية**.
- القلوب 3؛ عند السقوط في الفراغ تعود لآخر نقطة حفظ (مصابيح الحفظ تتوهّج باللون الأخضر حين تلمسها).

عناصر المراحل: منصات متحركة وطائرة، منصات تنهار، منصات أشباح (تظهر وتختفي أو تعمل بمفتاح)، نطّاطات، منصات سرعة، تيارات هوائية،
فقاعات انعدام الجاذبية، سيور متحركة، مناشير، ليزر، أشواك، مدافع وطائرات أعداء، مصدّات ارتدادية، ومواجهة زعيم في المرحلة الأخيرة.

| # | المرحلة | الفكرة |
|---|---|---|
| 1 | محطة الانطلاق | تعلّم الحركات: قفز، قفز مزدوج، اندفاع، منصات متحركة، نطّاطة، منصة سرعة |
| 2 | حدائق الكريستال | كريستالات تنهار، منصات أشباح، جسر بمفتاح، برج حلزوني، ساحة مصدّات، أشواك |
| 3 | مصنع الجاذبية | سيور عكسية ومناشير، عمود هواء، ليزر، فقاعة انعدام جاذبية، معرض مدافع |
| 4 | قلب المجرة | سباق سرعة ثم ساحة الزعيم العملاق |

كل مرحلة مفتوحة بعد إنهاء السابقة، وتُحفظ أفضل النتائج تلقائياً.

## 4) هيكل المشروع
```
project.godot            الإعدادات (Autoload: Game, Sfx — أفقي — Jolt Physics — Mobile renderer)
scenes/main.tscn         المشهد الجذر (يشغّل scripts/main.gd)
scripts/core/            game.gd (الإعدادات/الحفظ/كتالوج المراحل)، sfx.gd (الصوت)
scripts/ui/              القوائم، الأزرار النيون، التحكم اللمسي، HUD، الإعدادات
scripts/game/            اللاعب، الكاميرا، البيئة، المواد، المؤثرات، GameWorld، محمّل المراحل
scripts/game/objects/    المنصات، المقتنيات، المناطق، الأخطار، الأعداء، الزعيم
shaders/                 16 شيدر (سماء فضائية، منصات، نيون، أشباح، بوابة، ...)
assets/                  الصوت (WAV مُولَّد) والخط
levels/                  level_1..4.json (مولَّدة بـ tools/build_levels.py)
docs/level_maps/         خرائط علوية لكل مرحلة (PNG)
tools/                   أدوات التوليد والفحص (Python)
PROGRESS.md              ملف التسليم لمتابعة العمل في الدفعات القادمة
```

## 5) التخصيص السريع
- **إحساس الحركة**: الثوابت أعلى `scripts/game/player.gd` (RUN، JUMP_VEL، GRAVITY، HOVER_TIME، DASH …).
- **الكاميرا**: `scripts/game/camera_rig.gd` (مسافة، زاوية، سلاسة).
- **ألوان/أجواء العوالم**: `EnvBuilder.theme()` في `scripts/game/env_builder.gd`.
- **المراحل**: عدّل `tools/build_levels.py` ثم شغّل `python3 tools/build_levels.py` — يتحقق تلقائياً من أن كل قفزة ممكنة
  بحسب أرقام اللاعب، ويولّد JSON والنسخة المضمّنة وخرائط PNG. (أو عدّل ملفات JSON مباشرة.)
- **الصوت**: `python3 tools/make_audio.py` (يتطلب numpy) يعيد توليد ملفات WAV.

## 6) الأدوات (Python 3)
| الأداة | وظيفتها |
|---|---|
| `tools/build_levels.py` | تصميم المراحل بلغة بسيطة + فحص إمكانية القفز والتداخل + توليد JSON/GDScript/خرائط |
| `tools/check_gd.py` | فاحص ساكن لـ GDScript: أسماء، وسائط الدوال، أنواع المتغيرات، `:=` الخطر، بقايا Godot 3 … (`--api` يطبع واجهات المحرك المستخدمة) |
| `tools/check_shaders.py` | يطابق أسماء بارامترات الشيدر بين السكربتات وملفات `.gdshader` |
| `tools/check_schema.py` | يطابق مفاتيح JSON مع ما تقرؤه فئات GDScript |

## 7) الخطوات التالية المقترحة
1. تشغيل أول والتقاط الأخطاء وضبط الإحساس (سرعة، ارتفاع القفز، الكاميرا) على الهاتف.
2. دفعة محتوى: عوالم 5–8 بآليات جديدة (قلب الجاذبية، رياح، منصات مغناطيسية)، وعالم مركزي (Hub).
3. تلميس بصري/صوتي: جسيمات أكثر، أزياء للروبوت تُفتح بالأصدقاء المُنقَذين، موسيقى لكل عالم.
