# تصميم المسارات v8 — فلسفة CTR: Nitro-Fueled

هذا المستند يشرح ما تم بناؤه فعلياً في الإصدار v8، وكيف تحقق كل طلب من طلباتك، وكيف تُعدِّل المسارات بنفسك.
كل الأرقام هنا **مقاسة من محرك Godot الحقيقي** (وليست حسابات نظرية).

---

## 1. كيف تُصنع المسارات الآن (البنية الجديدة)

| الطبقة | الملف | ماذا يفعل |
|---|---|---|
| مصمم المسارات | `tools/trackgen/core.py` | يرسم المسار كمضلّع مغلق: نقاط + نصف قطر لكل منعطف (قوس دقيق)، ثم قنوات للارتفاع/العرض/الميلان/التحدّب، وخصائص لكل مقطع (نوع الأرضية، الحواف، السقف، أرضي/معلّق/فراغ، المنطقة). يضيف القفزات الحقيقية والمطبات والقمم، ويتحقق من عدم تداخل الطرق ومن المسافة الرأسية بين الطوابق (≥ 8.5 م). |
| حلّال الاختصارات | `core.py → shortcut_auto` | يضع منصة القفز على حافة الطريق بزاوية ≤ 45° عن اتجاه الطريق، ويمد خطها حتى يلتقي بالجزء اللاحق من المسار، ثم **يحسب ميل المنصة بالفيزياء** بحيث: سرعة القاعدة لا تكفي، والسرعة المطلوبة (Sacred / Blue) + القفزة تكفي. |
| مولّد العالم | `tools/trackgen/world.py` | تضاريس حقيقية تلتف حول الطريق (أكتاف مستوية، منحدرات، جروف، أودية تحت الفجوات)، أنهار وبحيرات وحمم وحمض، توزيع آلاف العناصر بكثافة مع مراعاة البعد عن الطريق وخطوط طيران الاختصارات، كتل ضخمة (الهرم المدرّج بممرات محفورة داخله)، وبوابات. |
| المسارات | `track_emerald.py`, `track_biolab.py`, `track_cosmic.py` | تعريف كل مسار منطقة بمنطقة. |
| البناء في Godot | `scripts/tracks/TrackBuilder.gd`, `TrackWorld.gd`, `TrackProps.gd`, `TrackShortcuts.gd`, `TrackMats.gd` | يقرأ `data/tracks/<id>.json` ويبني كل شيء خلال ~1 ثانية. |
| فيزياء الأرضيات | `scripts/physics/Surfaces.gd` | جدول لكل أرضية: السرعة، التماسك، التسارع، التوجيه، استهلاك الـ Reserves. |

لإعادة توليد المسارات بعد أي تعديل:
```bash
cd tools/trackgen
python3 build_all.py            # كل المسارات  (يتطلب numpy, scipy, matplotlib)
python3 build_all.py emerald    # مسار واحد
```
تُحفظ خريطة كل مسار مع مقطعه الرأسي في `docs/tracks/<id>_map.png`.

## 2. المسارات الثلاثة

### المسار 1 — حلبة المعبد الزمردي (2.54 كم)
| المنطقة | نوع التحدي | الأرضية | الحواف |
|---|---|---|---|
| ساحة القرية (البداية) | طريق حرّ عريض 30 م | حجر | سياج منخفض |
| شيكان السوق | قرارات سريعة: S ضيق + بسطات سوق في المسارات | حصى | جدران أكواخ |
| قفزة وادي النهر | نزول ثم **قفزة حقيقية فوق النهر** (Hang Time) | تراب + خشب | مفتوحة على الوادي |
| منعطفات الغابة | طريق راحة/انزلاق طويل، مطبات، **أكتاف عشبية يمكن قطعها** | تراب | كتف عشبي |
| درج المعبد | صعود حاد مدرّج، العرض يضيق 22→19 م، مسلّة تقسم المسار | حجر | جدران |
| **داخل الهرم** (مغلق) | 90° يمين، أعمدة متعرجة، 90° يسار، صخرة متدحرجة، نبتة مفترسة، منحدر صاعد داخلي | حجر | جدران + سقف |
| شرفة القمة | مرتفعة 27 م، مفتوحة على الفراغ، **U-Turn** مائل | حجر | مفتوحة/درابزين |
| جسر الأشجار الخشبي | معلّق ضيق 17 م، مطبات، **جسر مكسور (قفزة)**، يمر **فوق** وادي النهر بفارق 14 م | خشب | درابزين |
| كهف الشلال (مغلق) | تمر **خلف الشلال**، أرضية مبللة زلقة، صواعد في المسار، **سقوط من حافة** عند المخرج | حجر مبلل | جدران + سقف |
| شاطئ البحيرة | منعطف عريض 28 م ومائل حول البحيرة | حصى + رمل | كتف رملي |
| ممر الأطلال | ضيق 19 م، بندولات، 90° يسار | حصى | جدران |
| العودة للقرية | **قمة تقذفك** قبل خط النهاية | حجر | سياج |

**الاختصارات (قفز فقط):**
1. **قفزة كسر منعطف القمة** — درابزين مكسور ومنصة حجرية عند منعطف 90° المعلّق → قفزة مباشرة فوق الفراغ إلى الجسر الخشبي (Sacred Fire + قفزة).
2. **حجر البحيرة العائم** — منصة خشبية على الشاطئ → حجر عائم فوق المياه العميقة (عليه منحدر صغير) → قفزة ثانية إلى الطريق (تتطلب توقيت القفزة الثانية).
3. **قفزة جدار الأطلال** — منحدر متهدم قبل منعطف 90° → فوق جدار الأطلال → المستقيم التالي.

## 4. التصادم (المشكلتان المطلوبتان)
- **المجسمات بلا تصادم:** كل شجرة وصخرة وكوخ ومسلة وعمود وجدار وبرج له الآن جسم تصادم حقيقي، والتضاريس نفسها لها تصادم (لا يمكن السقوط عبرها). مُختبر بقيادة حقيقية نحو مجسمات من العالم.
- **قوة الاصطدام حسب صلابة الجسم:** `soft` (شجيرات، أكوام ثلج: مسح خفيف بلا فقدان) / `medium` (خشب، أسوار، بسطات، صناديق: يفقد ثلث السرعة و1 فاكهة) / `heavy` (حجر، فولاذ، أشجار، أبراج: ارتداد ويفقد الـ Reserves و2–3 فاكهة).
- **الأرضيات التي توقف المركبة:** كل الطريق والأكتاف جسم تصادم **واحد متصل** (لا فواصل)، والأرضية تُعرف من نقطة التلامس. الحواف المرتفعة للجدران لا تُعامل كأرضية، والمركبة المحشورة أمام جسم صلب لم تعد "تدور في مكانها". النتيجة: **صفر حالات توقف** في لفة كاملة على المسارات الثلاثة.

## 5. الاختبارات (فيزياء حقيقية)
```bash
godot --headless --fixed-fps 60 res://tests/VerifyV8.tscn            # كل المسارات
godot --headless --fixed-fps 60 res://tests/VerifyV8.tscn -- tracks=0 parts=shortcuts
```
| الاختبار | ماذا يثبت |
|---|---|
| structure | الطول ≥ 2 كم، ≥ 8 مناطق، ≥ 4 أرضيات، أجزاء مغلقة ومعلّقة، فجوات قفز، تنوع المنعطفات (90° / U-Turn / منحنيات طويلة)، حواف مفتوحة ومغلقة |
| drive | سائق آلي يقود لفة كاملة بسرعة القاعدة: بلا توقف، بلا سقوط، والقفزات تعطي Hang Time |
| shortcuts | كل اختصار يُجرّب **فعلياً** 5 مرات: قاعدة / قاعدة+10 فاكهة / النار المطلوبة / النار+فاكهة / Blue |
| ai | 6 مركبات ذكية تتسابق 100 ثانية وتكمل أكثر من لفة |
| collide | المركبة تُدفع نحو مجسمات حقيقية من العالم وتُسجّل قوة الاصطدام |
